How I Work

AI writes more of the code every year. My job is to make sure it writes the right code, so I move the thinking earlier: design before coding.

🧭 Think before coding

Decisions, constraints and contracts are written down first. Agents get context they can't misread, and reviewers get something concrete to approve.

📁 One source, many agents

A single specs/ folder feeds every coding agent. No copy-pasted prompts drifting out of sync across tools.

🛡️ Guardrails over hope

Schema validation, contract tests and CI checks catch what the model gets wrong, so production behaviour stays predictable.
